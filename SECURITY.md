# Security Policy

## Reporting a vulnerability

Please do not open GitHub issues or pull requests for security concerns - this makes the problem immediately visible to everyone, including malicious actors.

Security issues in this open-source project can be safely reported to Fifth Third's [Vulnerability Management Team](https://hackerone.com/fifth_third_bank_vdp?type=team).

Fifth Third's security team will triage your report and respond according to its impact on users and systems.

## Scope notes for LUCY

- Vulnerabilities **in LUCY itself** (the launcher, gates, toolbox, custody or redaction machinery) belong in the private channel above.
- Vulnerabilities **found by LUCY in your own applications** are yours to handle through your own disclosure process - never post scan findings, reports, or receipts to this repository.
